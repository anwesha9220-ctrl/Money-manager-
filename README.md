# 💰 Money Manager

A simple Money Manager built using Python to keep track of daily income and expenses.

This project helps users record their transactions, manage their spending, and understand where their money goes. Expenses can be divided into different categories like Food, Travel, Shopping, etc., making it easier to keep track of daily spending.

## ✨ Features

- Add and record income.
- Track daily expenses.
- Categorize expenses.
- View saved transactions.
- Store financial records using JSON.
- Access previously saved data.

## 🛠️ Technologies Used

- **Python** – Main programming language.
- **JSON** – Used for storing transaction data.

## ▶️ How to Run

1. Clone or download this repository.
2. Make sure Python is installed on your system.
3. Open the project folder in VS Code.
4. Run the main Python file:

   ```bash
   python main.py
   ```
